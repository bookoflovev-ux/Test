# 🎈 Jouons & Apprenons

Un **jeu éducatif interactif** pour les enfants de **3 à 12 ans**. Moderne, coloré,
responsive (mobile, tablette, ordinateur) et **100 % hors-ligne** : tout tient
dans un seul fichier `index.html`, sans installation ni connexion internet.

## ▶️ Comment jouer

Ouvre simplement **`index.html`** dans n'importe quel navigateur (double-clic).
Aucune installation nécessaire.

1. L'enfant **choisit son âge** (de 3 à 12 ans).
2. Le menu affiche uniquement les **jeux adaptés à son âge**.
3. On joue, on gagne des **⭐ étoiles**, on est encouragé à chaque bonne réponse !

## 🎯 Objectif : apprendre en s'amusant

Les jeux s'adaptent automatiquement à trois niveaux :

| Tranche | Âge | Contenu |
|---------|-----|---------|
| 🐣 **Petits** | 3-5 ans | compter, couleurs, formes, première lettre |
| 🌟 **Moyens** | 6-8 ans | additions/soustractions, lettre manquante, lecture, logique |
| 🚀 **Grands** | 9-12 ans | multiplications, divisions, problèmes, orthographe, quiz de culture |

## 🕹️ Les jeux

| Jeu | Ce qu'on apprend |
|-----|------------------|
| 🔢 **Calcul Malin** | compter, additions, soustractions, multiplications, divisions, petits problèmes |
| 🔤 **Les Mots** | première lettre, lettre manquante, orthographe |
| 🔍 **Chasse aux Objets** | observation — trouve des objets **autour de toi**, à l'intérieur 🏠, à l'extérieur 🌳 ou en mode mixte (« J'ai vu une caravane ! ») |
| 🧠 **Memory** | mémoire et concentration (grille qui grandit avec l'âge) |
| 🎨 **Couleurs & Formes** | reconnaître les couleurs et les formes |
| 🕵️ **Trouve l'Intrus** | logique, catégories, raisonnement |
| 🌍 **Quiz Découverte** | animaux, nature, sciences, géographie, culture générale |
| 📒 **Cahier de Vacances** | tous les défis mélangés, comme un vrai cahier d'activités |

## ✨ La Chasse aux Objets (le jeu d'observation)

Inspirée du jeu « Je vois quelque chose que tu ne vois pas », c'est un vrai
jeu à faire **dans la vraie vie** :

- On choisit **Intérieur**, **Extérieur** ou **Mixte**.
- Une liste d'objets à repérer apparaît (adaptée à l'âge).
- Dès que l'enfant repère un objet autour de lui (une chaise, un nuage,
  une caravane, un panneau STOP…), il **coche** la case → 🎉
- Idéal pour un trajet en voiture, une promenade ou occuper un enfant à la maison.

## 🧩 Fonctionnalités

- 📱 **Responsive** : gros boutons tactiles, pensé mobile d'abord.
- 🔊 **Sons** de réussite / erreur (générés en direct, aucun fichier).
- 🎊 **Confettis** et messages d'encouragement.
- ⭐ **Système d'étoiles** pour motiver.
- 🎲 Contenu **généré aléatoirement** → jamais deux parties identiques.
- 🚫 **Sans publicité, sans collecte de données, sans internet.**

## 🛠️ Technique

- HTML + CSS + JavaScript pur (vanilla), **un seul fichier**.
- Aucune dépendance, aucun build.
- Sons via l'API Web Audio, animations en CSS.
