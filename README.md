# 🧱 Bric-à-Blocs

Un **jeu éducatif interactif** pour les enfants de **3 à 12 ans**. Moderne, coloré,
tactile et **100 % hors-ligne** : tout tient dans un seul fichier `index.html`,
sans installation ni connexion internet.

## ▶️ Comment jouer

Ouvre **`index.html`** dans n'importe quel navigateur (double-clic). Aucune installation.

1. L'enfant **choisit son avatar** (animal, robot, personnage fantastique).
2. Il **choisit son âge** (3 à 12 ans) → le menu n'affiche que les jeux adaptés.
3. On joue, on gagne des **⭐ étoiles**, on est encouragé à chaque réussite !

## 🎨 Identité visuelle

Style **« briques de jouet »** : aplats vifs, contours épais indigo, ombres franches
décalées (chaque bouton s'enfonce comme un vrai bouton physique), fond papier à pois.
Sons générés en direct, confettis, animations douces (et respect de
`prefers-reduced-motion`). Pensé **mobile d'abord**, entièrement responsive.

## 🕹️ Les jeux

| Jeu | Ce qu'on apprend |
|-----|------------------|
| 🧱 **Construction** | reproduire un modèle **bloc par bloc** (Maison, Camion, Bus, Train, Gare) + un mode **Libre** pour créer ce qu'on veut. Repérage dans l'espace, couleurs, logique. |
| 🔍 **Chasse aux Objets** | observation — trouve des objets **autour de toi** : **Maison 🏠, Magasin 🏪, Extérieur 🌳 ou Mixte 🔀**. On clique pour valider chaque trouvaille (« J'ai vu une caravane ! »). |
| 🔢 **Calcul Malin** | compter, additions, soustractions, multiplications, divisions, petits problèmes |
| 🔤 **Les Mots** | première lettre, lettre manquante, orthographe |
| 🧠 **Memory** | mémoire et concentration (grille qui grandit avec l'âge) |
| 🎨 **Couleurs & Formes** | reconnaître les couleurs et les formes |
| 🕵️ **Trouve l'Intrus** | logique, catégories, raisonnement |
| 🌍 **Quiz Découverte** | animaux, nature, sciences, géographie, culture générale |
| 📒 **Cahier de Vacances** | tous les défis mélangés, comme un vrai cahier d'activités |

## 🎯 Trois niveaux automatiques

| Tranche | Âge | Contenu |
|---------|-----|---------|
| 🐣 **Petits** | 3-5 ans | compter, couleurs, formes, première lettre, modèles simples |
| 🌟 **Moyens** | 6-8 ans | additions/soustractions, lettre manquante, lecture, logique |
| 🚀 **Grands** | 9-12 ans | multiplications, divisions, problèmes, orthographe, quiz de culture |

## 🧱 Le jeu de Construction

- Choisis un modèle (🏠 Maison, 🚚 Camion, 🚌 Bus, 🚂 Train, 🚉 Gare) ou le mode **🎨 Libre**.
- Un **aperçu** du modèle et un **guide fantôme** sur la grille montrent où poser les blocs.
- Sélectionne une couleur dans la palette, tape une case pour poser un bloc (retape pour l'enlever, ou utilise la **🧽 gomme**).
- Quand la grille correspond au modèle → 🏆 **+3 étoiles** et confettis !
- En mode **Libre**, palette complète, aucune contrainte : on construit ce qu'on imagine.

## 🔍 La Chasse aux Objets

Un vrai jeu à faire **dans la vraie vie** (idéal en voiture, en balade, en courses
ou à la maison) :

- On choisit le lieu : **Maison**, **Magasin**, **Extérieur** ou **Mixte**.
- Une liste d'objets à repérer apparaît, adaptée à l'âge.
- Dès que l'enfant repère un objet autour de lui (une télé, un cadre, une caravane,
  un caddie, un panneau STOP…), il **coche** la case → 🎉

## 🛠️ Technique

- HTML + CSS + JavaScript pur (vanilla), **un seul fichier**, aucune dépendance, aucun build.
- Sons via l'API Web Audio, animations et rendu des blocs en CSS.
- **Sans publicité, sans collecte de données, sans internet.**
